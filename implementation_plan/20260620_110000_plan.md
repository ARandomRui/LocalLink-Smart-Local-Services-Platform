# Two-Factor Authentication (2FA) Implementation Plan

## Goal Description
The goal is to implement Two-Factor Authentication (2FA) into the LocalLink-Smart-Local-Services-Platform to enhance security during user login. 

## Open Questions & Clarifications
Before proceeding, we need to clarify which 2FA method to implement:
1. **App-based TOTP (Time-based One-Time Password)**: Uses apps like Google Authenticator. Requires new dependencies (`pyotp`, `qrcode`).
2. **Email-based OTP**: Sends a 6-digit code via email. Uses the already existing `Flask-Mail` dependency.

## Proposed Changes

### 1. Database Model Updates
- Add `two_factor_enabled` (Boolean) to the `User` model.
- Add `two_factor_secret` (String) to the `User` model.

### 2. Dependency Management
- If App-based TOTP is chosen: Add `pyotp` and `qrcode` to `requirements.txt`. (Will use `scan_dependencies` tool to verify safety before adding).

### 3. Route Modifications (Separation of Concerns)
Per the project rules, we should start separating concerns:
- Move authentication routes to a new file `auth.py`.
- Update the `/login` route:
  - Step 1: Verify username/password. If correct, store `user_id` in a temporary secure session cookie (not logging the user in yet).
  - Step 2: Redirect to `/verify_2fa`.
- Add `/verify_2fa` route:
  - Check the temporary session.
  - Verify the TOTP or Email code.
  - If successful, call `login_user()` and clear the temporary session.
- Add `/setup_2fa` route for users to enable 2FA from their profile.

### 4. UI Updates
- Create `verify_2fa.html` template for the OTP input form.
- Create `setup_2fa.html` template to display the QR code (for TOTP) or email verification prompt.
- Update `profile.html` to include a button to enable/disable 2FA.

## Verification Plan
1. **Automated Tests**: Write basic unit tests to ensure standard login fails without 2FA if enabled, and succeeds with valid 2FA.
2. **Manual Verification**: 
   - Register a new user.
   - Enable 2FA in the profile.
   - Log out and log back in to verify the 2FA prompt appears.
   - Enter an incorrect code (should fail).
   - Enter the correct code (should succeed and log in).
